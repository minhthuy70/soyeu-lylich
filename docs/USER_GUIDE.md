## Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Valid email address
- Internet connection

### Accessing the Application
1. Open your web browser
2. Navigate to the application URL
3. You will see the login page

## Registration

### Creating an Account
1. Click "Register" on the login page
2. Fill in the registration form:
   - Email address
   - Password (minimum 8 characters, including uppercase, lowercase, number, and special character)
   - Full name
3. Click "Register"
4. Check your email for verification link
5. Click the verification link to activate your account

### Social Login
You can also register using social accounts:
- Google
- GitHub
- Facebook
- LinkedIn

Click the corresponding social login button and authorize the application.

## Profile Management

### Personal Information
1. Navigate to "Profile" from the menu
2. Click "Personal Information" section
3. Fill in your details:
   - Full name
   - Job title
   - Bio/summary
   - Phone number
   - Address
   - Website URL
4. Click "Save" to update

### Contact Information
1. In the Profile page, click "Contact Information"
2. Add your contact details:
   - Email (auto-filled from registration)
   - Alternative email
   - Phone
   - Address
3. Click "Save"

### Education
1. Click "Education" section
2. Click "Add Education"
3. Fill in:
   - Institution name
   - Degree
   - Field of study
   - Start date
   - End date
   - Description
4. Click "Save"

### Work Experience
1. Click "Experience" section
2. Click "Add Experience"
3. Fill in:
   - Company name
   - Job title
   - Start date
   - End date (or "Present" for current)
   - Description
   - Technologies used
4. Click "Save"

### Skills
1. Click "Skills" section
2. Choose skill category:
   - Technical skills
   - Soft skills
   - Language skills
   - Tool skills
3. Click "Add Skill"
4. Enter skill name and proficiency level
5. Click "Save"

## Projects

### Adding a Project
1. Navigate to "Projects" from the menu
2. Click "Add Project"
3. Fill in project details:
   - Project title
   - Description
   - Start date
   - End date
   - Technologies used
   - Project link (optional)
   - Status (in-progress, completed)
4. Click "Save"

### Uploading Project Images
1. In the project details, click "Add Image"
2. Select image file from your computer
3. Add caption and description
4. Click "Upload"

### Managing Projects
- **Edit**: Click the edit button on any project card
- **Delete**: Click the delete button (requires confirmation)
- **View**: Click on the project to see full details

## Achievements

### Adding an Achievement
1. Navigate to "Achievements" from the menu
2. Click "Add Achievement"
3. Fill in:
   - Achievement title
   - Description
   - Date achieved
   - Issuing organization
   - Certificate URL (optional)
4. Click "Save"

### Uploading Certificates
1. In the achievement details, click "Upload Certificate"
2. Select the certificate file (PDF, image)
3. Click "Upload"

## Integrations

### Connecting Social Accounts
1. Navigate to "Integrations" from the menu
2. Click "Connect" next to the desired provider:
   - Twitter
   - Slack
   - Notion
   - Google Calendar
3. You will be redirected to the provider's authorization page
4. Authorize the application
5. You will be redirected back with the integration active

### API Key Integration
For services like SendGrid, Twilio, Stripe:
1. Click "Connect" on the service card
2. Enter your API key
3. Click "Save"

### Managing Cloud Storage (AWS S3)
1. Click "Connect" on AWS S3
2. Enter your AWS credentials
3. Click "Save"
4. You can now upload files directly to S3

### Disconnecting Integrations
1. In the "Your Integrations" section
2. Click "Disconnect" on any integration
3. Confirm the disconnection

## Analytics

### Viewing Analytics Dashboard
1. Navigate to "Analytics" from the menu
2. The dashboard shows 6 tabs:
   - **Overview**: Summary statistics
   - **User Behavior**: Event history
   - **Sessions**: Session analytics
   - **Funnel Analysis**: Funnel performance
   - **A/B Testing**: Test results
   - **Retention**: Retention metrics

### Creating a Funnel
1. Click "Funnel Analysis" tab
2. Click "Create Funnel"
3. Enter funnel name
4. List steps (one per line)
5. Click "Create"

### Viewing Funnel Analytics
1. In the "Funnel Analysis" tab
2. Enter funnel name
3. Click "Load"
4. View step-by-step completion rates

### Creating an A/B Test
1. Click "A/B Testing" tab
2. Click "Create Test"
3. Fill in:
   - Test name
   - Description
   - Variant A
   - Variant B
   - Traffic split percentage
4. Click "Create"

### Viewing A/B Test Results
1. In the "A/B Testing" tab
2. Enter test name
3. Click "Load"
4. View variant comparison and conversion rates

## Settings

### Profile Settings
1. Navigate to "Settings" from the menu
2. Configure:
   - Theme (light/dark)
   - Language (English/Vietnamese)
   - Font size (small/medium/large)
   - Animations (on/off)
3. Click "Save"

### Account Settings
1. In Settings, click "Account"
2. You can:
   - Change password
   - Enable two-factor authentication
   - View active sessions
   - Logout from all devices

### Security
1. In Settings, click "Security"
2. Configure:
   - Login notifications
   - Password expiry
   - Session timeout

## Accessibility

### Keyboard Navigation
- Use Tab to navigate between interactive elements
- Use Shift+Tab to navigate backwards
- Use Enter to activate buttons and links
- Use Escape to close modals

### Screen Reader Support
The application is designed to work with screen readers like NVDA and JAWS.

### Adjusting Text Size
Go to Settings and select your preferred font size.

## Troubleshooting

### Cannot Login
- Verify your email and password
- Check if your account is locked (contact support)
- Reset your password if needed

### Cannot Save Profile
- Check your internet connection
- Verify all required fields are filled
- Try refreshing the page

### Integration Not Working
- Verify your API keys are correct
- Check if the provider's service is operational
- Try disconnecting and reconnecting

### Images Not Uploading
- Check file size (max 5MB)
- Verify file format (JPG, PNG, PDF)
- Check your internet connection
